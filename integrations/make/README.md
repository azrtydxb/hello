# Make app for Hello PBX

The files of a Make custom app: a connection (Hello URL and API token), the
instant trigger **Watch Call Events**, the actions **Place a Call**, **Get a Call
Record**, **List Calls**, **Find a Contact by Number** and **Make an API Call**.

Setup and what is not covered are in [docs/n8n-make.md](../../docs/n8n-make.md).

```sh
node --test test/
```
