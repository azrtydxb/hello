# n8n nodes for Hello PBX

A community node package: **Hello PBX Trigger** (call events and voicemail
messages) and **Hello PBX** (place a call, get or list call records, find a
contact by number). No dependencies and no build step.

Setup, the token's scopes, how the trigger verifies each delivery and what is
not covered are in [docs/n8n-make.md](../../docs/n8n-make.md).

```sh
node --test test/
```
