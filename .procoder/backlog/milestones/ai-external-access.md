# AI external access

Status: open
Created: 2026-10-07

## Goal

Phase 1 of the AI integration: an AI agent can operate Hello safely from outside. A user connects an MCP client to Hello, approves exactly what it may do on a consent screen, and the agent works through tools generated from a complete, test-checked API description, guided by skills shipped with Hello — scoped, expiring, revocable and audited, with no secret ever leaving through MCP. Phase 2 (the in-product agent) and phase 3 (voice agents) build on it.
